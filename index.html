Privacy, in plain language

Zero telemetry.
Clear boundaries.

No usage analytics. No remote crash reporting. Network providers and optional services can still receive your IP address and the requests needed to provide their features.

Read the privacy notes
What does zero telemetry mean?

Zero telemetry means ECF Wallet doesn’t collect usage analytics or send remote crash reports. The analytics and reporting SDKs have been removed.

Requests for blockchain data, function names, or NFTs provide wallet features. They can still reveal information to the service receiving them. Zero telemetry doesn’t make those requests anonymous or blockchain transactions private.

Can network providers see my IP address?

Yes. The wallet connects to an RPC provider to read blockchain data, simulate transactions, and submit them. That provider receives your IP address and the information needed for each request. A transaction simulation is sent before approval, even if you later reject the transaction. You can choose a custom RPC.

Which features use outside services?

Contract method names

When the wallet looks up an unfamiliar contract function, it asks 4byte.directory. That service receives the function identifier and your IP address. This lookup is enabled by default. You can turn it off in Settings > Security & Privacy to stop these lookups.

NFT detection

NFT detection is off unless you turn it on. When enabled, it uses MetaMask’s NFT API (nft.api.cx.metamask.io) to list the selected account’s NFTs on Ethereum, Arbitrum, Optimism, Polygon, and Base. The service receives the account’s address and your IP address. Turning this feature off clears the NFT list. NFT images are also off by default. If you enable them, image hosts receive requests and your IP address.

Other connections

Phishing-list updates, ENS gateways, and hardware-wallet integrations can also contact outside services. The privacy notes document these connections.

How do approvals and phishing alerts work?

You choose what to approve

Closing the approval window refuses the transactions, signatures, and other requests waiting in it. You can turn this behavior off to leave requests waiting for later.

Warnings for phishing sites

The wallet checks domains against a phishing list locally and warns you about known threats. Visited sites are not sent to the list provider. Phishing detection and list updates are enabled by default; either can be turned off.
